# Faculty Feedback System

## 📌 Project Description

Faculty Feedback System is a web-based application developed using Spring Boot, Thymeleaf, HTML, CSS, and MySQL.  
The system allows students to provide feedback for multiple faculty members, and the admin can analyze and view the feedback in graphical format.


## 🛠 Technologies Used

- **Backend:** Spring Boot  
- **Frontend:** Thymeleaf, HTML, CSS  
- **Database:** MySQL    
- **Build Tool:** Maven  
- **IDE:** Spring Tool Suite(sts)

---

## 🚀 Features

### Admin Module
- Secure admin login  
- Insert student details  
- Insert faculty details  
- View feedback analysis  
- Graphical representation of feedback  

### Student Module
- Student login  
- View faculty list  
- Give feedback to multiple faculty  
- Submit feedback with ratings and comments  

---

## 🔄 System Workflow

1. User opens the application home page  
2. Admin logs in and inserts student and faculty data  
3. Students log in using credentials  
4. Students give feedback to 2 or more faculty members  
5. Admin views feedback analysis in graphical format  



## 📂 Modules

- Home Page  
- Admin Login  
- Student Login  
- Insert Student Data  
- Insert Faculty Data  
- Feedback Form  
- Feedback Analysis  



## 🗄 Database

Database used: **MySQL**

Main Tables:
- student  
- faculty  
- feedback  
- admin
